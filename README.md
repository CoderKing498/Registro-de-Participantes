📋 Sistema de Registro de Aspirantes


📌 Descripción

Este proyecto es un programa en Python que permite registrar aspirantes para un proceso de selección.

El sistema:

Solicita la cantidad de personas a registrar.

Pide nombre y edad de cada aspirante.

Valida que la edad sea un número positivo.

Consulta si tiene conocimientos básicos en computación.

Determina si puede participar según los requisitos.

🔄 Flujo del Programa

Bienvenida.

Solicitud del número de aspirantes.

Registro individual:

Nombre

Edad (validada)

Conocimientos básicos

Evaluación de requisitos.

Mensaje final de proceso terminado.

🧠 Lógica del Programa

El sistema aplica las siguientes reglas:

La edad debe ser un número entero positivo.

El aspirante debe tener 15 años o más.

Debe responder si o no a la pregunta sobre conocimientos básicos.
